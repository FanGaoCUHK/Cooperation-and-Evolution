### 策略描述

**初始行为**：第一轮选择合作（C）。

**核心参数**：
- 维护最近5轮对手的选择历史（包括当前轮的前一轮）。
- 记录对手最近5轮中背叛（D）的次数，记为 `betrayals`。
- 当前轮次 `t`（1~30），剩余轮数 `R = 30 - t + 1`。

**决策规则**：

1. **如果剩余轮数 `R ≥ 10`（前期和中期）**：
   - 若 `betrayals == 0` → 选择合作（C）。
   - 若 `betrayals == 1` → 选择合作（C）。（宽容一次背叛）
   - 若 `betrayals ≥ 2` → 选择欺骗（D）。（惩罚）

2. **如果剩余轮数 `5 ≤ R < 10`（后期前半段）**：
   - 若 `betrayals ≤ 1` → 选择合作（C）。（继续试探合作）
   - 若 `betrayals ≥ 2` → 选择欺骗（D）。（惩罚）

3. **如果剩余轮数 `R ≤ 4`（最后4轮）**：
   - 无论历史如何，始终选择欺骗（D）。（规避末期风险）

4. **特殊处理**：对手在任意轮次出现 `ERROR` 时，视为该轮对手选择背叛（D），计入历史。

5. **无随机机制**：完全确定性决策。
